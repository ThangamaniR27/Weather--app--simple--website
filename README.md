# 🌤 Weather App

A responsive Weather App built with **React** that fetches real-time weather data using the OpenWeatherMap API.

---

## 🚀 Features

* 🔍 Search weather by city name
* 🌡 Temperature in Celsius
* ☁ Weather condition display
* 💧 Humidity information
* 🌬 Wind speed details
* 🌤 Dynamic weather icons
* ⚠ Error handling for invalid input

---

## 🛠 Tech Stack

* React (Hooks)
* Axios
* Tailwind CSS
* OpenWeatherMap API

---

## 📦 Installation

Clone the repository:

git clone https://github.com/your-username/weather-app.git

Navigate into the project:

cd weather-app

Install dependencies:

npm install

Run the app:

npm start

---

## 🔑 API Setup

1. Visit https://openweathermap.org
2. Sign up and generate an API key
3. Add your API key in the code:

const API_KEY = "YOUR_API_KEY";

⚠ Note: API key activation may take 10–15 minutes.

---

## ▶ How to Use

1. Enter a city name
2. Click the Search button
3. View weather details instantly
